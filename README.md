# NHK v3

Project WordPress sạch, độc lập với project NHK cũ, dành cho thế hệ kiến trúc
Clean Architecture mới.

- WordPress core trong `public/`
- Plugin mới tại `public/wp-content/plugins/nhk-core/`
- Tài liệu tại `docs/architecture/`
- Tests tại `public/wp-content/plugins/nhk-core/tests/`

Plugin health endpoint: `/wp-json/nhk/v1/health`.

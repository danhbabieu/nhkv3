# NHK V3 — Frontend Design & UX Law

Public UI is Vietnamese-first and natural; internal PHP, registry and database
identifiers remain technical. Normal content pages use H1 40–48px desktop and
30–36px mobile, H2 24–32px, body text 16–18px with 1.6–1.75 line height,
restrained heading weights, and shared 48–72px desktop / 32–48px mobile gaps.

Header, content and footer use shared container widths and responsive gutters
that remain usable at 390px. Cards use consistent grids and explicit image
ratios without horizontal overflow. Pages use one meaningful H1, ordered
headings, semantic landmarks, visible focus, labelled forms and readable
contrast. Empty modules are hidden, never replaced by invented metrics.

NHK is an editorial discovery surface, not a generic SaaS dashboard: readable
Vietnamese titles, summaries, provenance and related content take priority over
oversized hero typography and dense technical metadata.
